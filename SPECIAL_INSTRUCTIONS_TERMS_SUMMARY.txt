🎯 WHAT WAS IMPLEMENTED
================================================================================

Two new checkbox-based sections for Purchase Order creation with intelligent
auto-fill capability:

  1️⃣ SPECIAL INSTRUCTIONS (Blue Theme)
     - 4 pre-defined checkboxes
     - Toggle to enable/disable
     - Comma-separated storage
     - Auto-fills on edit

  2️⃣ TERMS & CONDITIONS (Purple Theme)
     - 4 pre-defined checkboxes (with category titles)
     - Toggle to enable/disable
     - Comma-separated storage
     - Auto-fills on edit

================================================================================

💾 DATA STORAGE & RETRIEVAL
================================================================================

Storage Format: Comma-separated keys

Special Instructions Examples:
  • Only box 2: "paymentSchedule"
  • Boxes 1 & 3: "notReturnable,noLiabilityDelay"
  • All boxes: "notReturnable,paymentSchedule,noLiabilityDelay,invoiceVerified"

Terms & Conditions Examples:
  • Only box 2: "paymentAgreement"
  • Boxes 1 & 4: "returnPolicy,verificationConfirmation"
  • All boxes: "returnPolicy,paymentAgreement,deliveryLiability,verificationConfirmation"

Auto-Fill Feature:
  When editing existing PO:
  1. System detects comma-separated keys
  2. Parses into individual keys
  3. Matches to checkbox states
  4. Auto-checks corresponding boxes
  5. Expands section if any boxes are checked
  6. Shows previous selections for review

🚀 HOW TO USE
================================================================================

Creating a PO:
  1. Navigate to Procurement → Purchase Orders → Create New
  2. Fill Vendor and Items sections
  3. Click ✏️ Add Special Instructions (or skip)
  4. Check relevant boxes (or none)
  5. Click 📋 Add Terms & Conditions (or skip)
  6. Check relevant boxes (or none)
  7. Submit PO
  8. Done! ✅

Editing a PO:
  1. Navigate to existing PO
  2. Click Edit
  3. Sections auto-expand with previous selections
  4. Modify if needed
  5. Submit to save changes
