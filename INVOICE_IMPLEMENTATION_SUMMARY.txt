API ENDPOINTS (8 TOTAL):
================================================================================

✅ POST   /api/invoices/generate-from-sales-order/:salesOrderId
   → Generates professional PDF invoice from sales order

✅ POST   /api/invoices/generate-from-purchase-order/:purchaseOrderId
   → Generates professional PDF invoice from purchase order

   → Downloads invoice PDF file

   → Downloads attached document file

   → Deletes (soft-deletes) attached document

✅ POST   /api/invoices/:invoiceId/send-to-procurement
   → Sends invoice with attachments to procurement department
   → Auto-sends notifications to procurement, finance, admin

✅ GET    /api/invoices/:entityType/:entityId/documents
   → Lists all attachments for a specific entity

DATABASE SCHEMA:
================================================================================

New Table: document_attachments

  id                INT          Primary key
  entity_type       ENUM         sales_order|purchase_order|invoice|...
  entity_id         INT          ID of related entity
  document_type     ENUM         invoice|proforma|quotation|specification|...
  file_name         VARCHAR(255) Original filename
  file_path         VARCHAR(500) Server storage path
  file_type         VARCHAR(50)  MIME type
  file_size         INT          Size in bytes
  version           INT          Document version
  description       TEXT         Document description
  uploaded_by       INT FK       User who uploaded (→ users.id)
  is_active         BOOLEAN      Soft delete flag
  metadata          JSON         Custom data (invoice_number, etc.)
  created_at        TIMESTAMP    Creation time
  updated_at        TIMESTAMP    Last update time

Indexes:
  - entity_type + entity_id (for fast lookups)
  - entity_id (for filtering by entity)
  - document_type (for filtering by type)
  - uploaded_by (for audit trail)
  - created_at (for date range queries)
  - is_active (for active/deleted filtering)

NOTIFICATIONS WORKFLOW:
================================================================================

When invoice is sent to procurement:

1. Invoice status updated to "sent"
2. Sent date recorded
3. Notifications created for:
   - Procurement department (high priority)
   - Finance department (medium priority)
   - Admin (medium priority)

Notification includes:
  - Invoice number
  - Total amount
  - Vendor/Customer name
  - Number of attachments
  - Action URL to invoice detail page
  - 7-day expiration

TROUBLESHOOTING QUICK REFERENCE:
================================================================================

Problem: "Table doesn't exist"
Solution: node server/run-document-attachment-migration.js

Problem: "Can't write files"
Solution: mkdir -p server/uploads/documents && chmod 755 server/uploads/documents

Problem: "Invalid file type"
Solution: Use PDF, JPEG, PNG, Word (.docx), or Excel (.xlsx) files

Problem: "File too large"
Solution: Files must be under 10 MB

Problem: "Invoice PDF blank"
Solution: Ensure sales order has: customer_name, items, total_amount

Problem: "Notifications not sent"
Solution: Verify procurement department exists and users are assigned
